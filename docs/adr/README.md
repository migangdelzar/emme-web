# Architecture Decision Records

ADRs record consequential web decisions such as workspace boundaries, API
compatibility, authentication/session storage, PWA caching, browser security,
delivery runtime, and meaningful accessibility/performance trade-offs.

## Minimum content

- status and date;
- context and decision drivers;
- decision and scope;
- alternatives considered;
- consequences and migration cost;
- security, privacy, accessibility, and compatibility impact;
- verification evidence and rollback/supersession condition.

```text
Proposed → Accepted → Superseded
                    ↘ Deprecated
```

Do not delete historical ADRs. Add a new record when a decision changes.
