# UI Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Make `@emme/ui` the generic, accessible visual system for web and future native implementations.

**Architecture:** Extract generic components from `apps/emme-salon-app/src/shared/ui`; keep business components in feature modules. Share tokens and component contracts across `web/` and `native/` boundaries.

**Tech Stack:** React 19, Testing Library, Vitest, existing Radix/Base UI, Tailwind utilities, `react-day-picker`, `sonner`.

## Global Constraints

- UI imports only React, visual dependencies, and local UI modules.
- Components expose accessible names, keyboard behavior, focus management, and deterministic states.
- No `Appointment`, `Salon`, `Tenant`, `Customer`, `Payment`, or `Booking` imports.
