# Core Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Centralize authentication, tenancy, permissions, configuration, routing contracts, feature flags, and error presentation in `@emme/core`.

**Architecture:** Core owns React runtime providers and stable contracts. It consumes API protocols but never constructs concrete infrastructure clients. Apps wire providers in `AppProviders.tsx`.

**Tech Stack:** React 19, TypeScript, Vitest, Testing Library, `@emme/api`, `@emme/kernel`.

## Global Constraints

- Frontend permission guards are UX only; backend authorization remains mandatory.
- Tenant context is explicit and cannot be derived from arbitrary UI state.
- Auth/session dependencies are injected through protocols.

## Files

- Modify: `packages/core/src/index.ts`, existing `auth/`, `tenancy/`, `access-control/`, `configuration/`, `runtime/`, and `errors/` modules.
- Create: `src/permissions/`, `src/feature-flags/`, `src/routing/`, `src/logging/`, and package boundary tests.
