# @emme/i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** Make translations and locale-aware presentation formatting reusable across all three apps.

**Architecture:** The package owns locale data, typed lookup, fallback behavior, and presentation formatters. It does not call APIs or contain business calculations.

**Tech Stack:** TypeScript, React, i18next/react-i18next, date-fns or existing formatter dependencies, Vitest, Bun.

## Global Constraints

- Preserve current `en-US`/`es-MX` key parity and 227 valid test IDs.
- Tenant time zone and currency are runtime values, never tenant-specific code branches.
- Translation keys and test IDs remain stable unless an explicit migration map is added.
- Translation and formatter tests are colocated or under package `src/__tests__/` for cross-module validation.

## Current inventory

- `packages/i18n/src/index.ts`, locale JSON files, `index.test.ts`, and validation script.
- `apps/emme-salon-app/src/app/translation.ts`, `src/i18n.ts`, and direct i18next setup.
- `packages/i18n/src/data/elements.json` and typed translation resources.
