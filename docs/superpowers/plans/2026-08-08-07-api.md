# API Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Define the framework-agnostic API contracts, transport protocols, tenant context, errors, pagination, and capability factories used by all features and apps.

**Architecture:** `@emme/api` describes how the frontend communicates; feature modules define which operations exist. Concrete HTTP and storage stay in infrastructure.

**Tech Stack:** TypeScript 5, Vitest, Zod only where contract validation requires it.

## Global Constraints

- No React, browser storage, concrete fetch, React Query, or Apollo React hooks.
- Contracts validate untrusted transport data at the boundary.
- API errors are normalized and safe for presentation.

## Files

- Modify: `packages/api/src/index.ts`, `common/`, `contracts/`, `auth/`, `ports/`, and existing capability modules.
- Create: `packages/api/src/client/api-client.ts`, `packages/api/src/client/api-request.ts`, `packages/api/src/client/api-response.ts`, `packages/api/src/client/index.ts`, `packages/api/src/tenant/tenant-request-context.ts`, `packages/api/src/tenant/index.ts`, `packages/api/src/contracts/api-error.ts`, `packages/api/src/contracts/page-info.ts`, `packages/api/src/contracts/cursor.ts`, and boundary tests.
