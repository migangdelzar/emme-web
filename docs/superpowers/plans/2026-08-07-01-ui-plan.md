# @emme/ui Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** Extract generic visual primitives and reusable UI behavior from the salon app into `@emme/ui`.

**Architecture:** The package is React-only and business-agnostic. Generic components are exported from package and component barrels; business components remain in app features or `@emme/features`.

**Tech Stack:** React 19, TypeScript, Testing Library, existing styling and accessibility dependencies, Bun, Vitest.

## Global Constraints

- No imports from `@emme/domain`, `@emme/application`, `@emme/api`, `@emme/infrastructure`, or app paths.
- Use PascalCase component directories/files and colocated `Component.test.tsx`.
- Preserve existing visual behavior and `data-testid` contracts.
- Interactive components must test keyboard, disabled, loading, and accessible-name behavior.

## Current inventory

- Package source: `packages/ui/src/index.ts` is currently a shell.
- App primitives: `apps/emme-salon-app/src/shared/ui/*.tsx`.
- App shared components: `apps/emme-salon-app/src/shared/components/ErrorBanner.tsx` and `ErrorBoundary.tsx`.
- App utility classes: `apps/emme-salon-app/src/shared/lib/utils.ts`.
