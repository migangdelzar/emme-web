# Internationalization

`@emme/i18n` owns the engine, locale selection, providers, shared catalogs, formatters, and test providers. A reusable feature owns its namespace; app-only workflow copy remains app-local. Message IDs and formatting are stable public behavior, not ad hoc literals in shared UI.

Locale changes preserve user-safe error categories and formatting. Tests use the shared test provider and cover fallback, missing-message detection, locale-sensitive date/number output, and feature namespace isolation.
