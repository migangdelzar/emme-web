# Documentation and Decisions

The handbook is the durable target architecture. The approved [complete monorepo design](../../superpowers/specs/2026-08-08-complete-monorepo-architecture-and-plan-portfolio-design.md) and [plan portfolio](../../superpowers/plans/2026-08-08-00-complete-monorepo-index.md) define its implementation sequence. Earlier migration plans are historical artifacts and are not rewritten.

Record an ADR for consequential changes to workspace boundaries, contracts, auth/session storage, caching, browser security, delivery runtime, or material accessibility/performance trade-offs. Each ADR names context, decision, consequences, owner, and superseded decision where applicable.

Documentation must use resolvable relative links, current Bun commands, and no credentials or private recordings. Diagrams require nearby prose that states their invariant.
